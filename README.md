# Collatz-Conjecture
Enter a number to see the steps it takes to reach 1! The number will go through a process where it is divided by 2 if it is even, and multiplied by 3 plus 1 if it is odd.

## Installation
1. Download this repository in the terminal: `git clone https://github.com/StefiBad/Collatz-Conjecture`
2. Enter inside the directory: `cd Collatz-Conjecture`
3. Run the program: `./run.cpp`
4. If step 3 didn't work due to a lack of execution permissions, type: `chmod +x run.cpp` and repeat the previous step!

## Features
1. Show the proccess of the number selected until it reaches 1 by the 3x+1 algorithm.
2. Count the total amount of steps during the proccess!
